# Tavonga Sumani — Portfolio

Modern, futuristic student developer portfolio website (dark theme + neon accents + subtle “speed / F1 dashboard” motion).

## Run locally

### Option A: Open directly
- Open `index.html` in your browser.

### Option B: Local server (recommended)
From the `tavonga-portfolio/` folder:

**PowerShell**
```powershell
python -m http.server 5173
```

Then open `http://localhost:5173`.

## Customize quickly

- **Contact details**: update the phone/email/LinkedIn/GitHub in `index.html` (search for `tavongasumani@gmail.com`).
- **Project links**: replace placeholder GitHub + Live Demo links in the Projects section.
